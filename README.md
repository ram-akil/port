# DELEXWEBDEV Portfolio

A responsive static portfolio website for DELEXWEBDEV.

## Included
- `index.html` — complete website structure
- `style.css` — responsive styling and animations
- `script.js` — mobile menu, current year and demo contact-form behavior
- `assets/delex-logo.png` — supplied DELEX image
- `README.md` — this file

## Before deployment
1. Open `index.html` locally and test the pages.
2. Replace the sample project cards with real project screenshots/details when available.
3. Connect the contact form to a form/email service if you want real submissions.
4. Add a real domain and hosting only when you are ready. This project does not require a purchased domain to develop or preview.
5. Compress/optimize large images before production deployment.
6. Test on Chrome/Edge/Safari and on a phone.
7. If using Git, initialize a repository and push the project files.

## Tech
HTML5, CSS3 and vanilla JavaScript. No framework is required.

## Important
The portfolio intentionally does not contain personal phone numbers, addresses, college information or other private details.
